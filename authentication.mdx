You will need an API key for every request you make. It's how Baag knows who you are and which store's products to send back.

Your API key looks like this:

```bash
pk_live_xxxxxxxxx
```

<Warning>
**Every request needs your API key.** Without it, Baag doesn't know which store you are, and the request fails. If you regenerate your key in **Baag App**, the old one stops working right away, so update your website with the new one.
</Warning>

## How to send your key

Put your key in the `Authorization` header of each request, after the word `Bearer` and a space:

```bash
Authorization: Bearer pk_live_xxxxxxxxx
```

For example, this is how you can get your store's details from your website:

```javascript
const response = await fetch("https://api.baag.cc/v1/store", {
  headers: { Authorization: "Bearer pk_live_xxxxxxxxx" },
});
const store = await response.json();
```

This one key works for every endpoint in these docs, and it's safe to use in your website's code.

## Key errors

If something is wrong with your key, you will get one of these errors back, on any endpoint.

<AccordionGroup>
  <Accordion title="Missing API key">
    Returned with status `401` when the request has no `Authorization` header. Add your key as shown above.

    ```json
    {
      "error": {
        "code": "missing_api_key",
        "message": "Send your API key as: Authorization: Bearer <key>."
      }
    }
    ```
  </Accordion>
  <Accordion title="Invalid API key">
    Returned with status `401` when the key is wrong, or it was regenerated in **Baag App**. Copy your key again from **Settings** → **Developers**.

    ```json
    {
      "error": {
        "code": "invalid_api_key",
        "message": "That API key isn't valid. It may have been regenerated."
      }
    }
    ```
  </Accordion>
  <Accordion title="Plan required">
    Returned with status `403` when your store's plan doesn't include the API. Your key works again as soon as your store is on the **Basic** or **Pro** plan.

    ```json
    {
      "error": {
        "code": "plan_required",
        "message": "This store's plan doesn't include API access."
      }
    }
    ```
  </Accordion>
  <Accordion title="Rate limited">
    Returned with status `429` when your key sent too many requests in a short time. Wait a moment, then try again.

    ```json
    {
      "error": {
        "code": "rate_limited",
        "message": "Too many requests. Slow down and try again shortly."
      }
    }
    ```
  </Accordion>
</AccordionGroup>
