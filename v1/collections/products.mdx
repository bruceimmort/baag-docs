---
title: 'Collection products'
openapi: 'GET /v1/collections/{id}/products'
---

Get the products in one collection, a page at a time.

```method: GET
https://api.baag.cc/v1/collections/{id}/products
```

## Authorization

Use your **public** or **secret** key.

```bash
Authorization: Bearer pk_live_xxxxxxxxx
```

<ParamField header="Authorization" type="string" required>
  `Bearer` followed by your public or secret key.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The collection's `id`, from [All collections](/v1/collections/list).
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="20">
  How many products per page, from 1 to 100. Above 100 returns 100.
</ParamField>

<ParamField query="cursor" type="string">
  The `nextCursor` from the previous page. Leave it out for the first page.
</ParamField>

## Response

Returned with status `200`.

Same shape as [All products](/v1/products/list).

```json
{
  "data": [
    {
      "slug": "mw6",
      "name": "Linen Shirt",
      "priceRange": {
        "min": 25000,
        "max": 28000
      },
      "isSoldOut": false,
      "imageUrl": "https://…/mw6-red.jpg",
      "colors": [
        {
          "name": "Red",
          "hex": "#C0392B"
        },
        {
          "name": "Navy",
          "hex": "#1F2A44"
        }
      ]
    }
  ],
  "nextCursor": "cm8x3a9fd0007l70fh1k2p4qr"
}
```

<Note>Newest first. Pass `nextCursor` as `cursor` to get the next page. `null` means it's the last page.</Note>

## Error Responses

<AccordionGroup>
  <Accordion title="Invalid limit">
    Returned with status `400` when `limit` is below 1 or not a whole number.

    ```json
    {
      "error": {
        "code": "invalid_limit",
        "message": "limit must be a whole number from 1 to 100."
      }
    }
    ```
  </Accordion>
  <Accordion title="Collection not found">
    Returned with status `404` when there's no collection with this id in the store.

    ```json
    {
      "error": {
        "code": "collection_not_found",
        "message": "No collection with the id \"cm8x2k1qv0003l70f9h2d5abc\"."
      }
    }
    ```
  </Accordion>
  <Accordion title="Internal error">
    Returned with status `500` when something went wrong on Baag's side. Retry.

    ```json
    {
      "error": {
        "code": "internal_error",
        "message": "Something went wrong on our side. Please try again."
      }
    }
    ```
  </Accordion>
</AccordionGroup>

Key errors (`401`, `403`, `429`) are on [API keys](/authentication#key-errors).
